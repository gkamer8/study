### Key terms

- **Sequencing**: reading the order of bases in DNA or RNA molecules.
- **Read**: one sequenced fragment, usually 50–300 bases with short-read (Illumina) machines.
- **Paired-end**: both ends of each DNA fragment are read, giving two linked reads (R1, R2).
- **Library**: the prepared pool of DNA fragments (with attached adapter sequences) that goes into the sequencer.
- **PCR**: a reaction that copies DNA many times. It creates **duplicates** of the same original molecule.
- **Reference genome / assembly / build**: the standard genome sequence that reads are compared against, released in versions (GRCh38…).
- **Alignment (mapping)**: finding where each read came from in the reference.
- **Coverage (depth)**: how many reads overlap a given position.
- **Genotype**: which alleles an individual carries at a locus (see Unit 1).
- **Phased**: it is known which alleles sit together on the same chromosome copy.
- **Interval**: a region given as chromosome, start, end.
- **0-based / 1-based**: whether the first base of a chromosome is numbered 0 or 1.
- **cDNA**: DNA copied from RNA by the enzyme reverse transcriptase, so RNA can be sequenced.
- **Normalization**: rescaling counts so samples are comparable.
- **Fold change**: the ratio of expression between conditions, usually reported as log2.
- **FDR**: false discovery rate, the expected fraction of false positives among results called significant.
- **Barcode / UMI**: short tags identifying the cell / the original molecule a read came from.
- **Sparse matrix**: a matrix that is mostly zeros, stored efficiently.
- **Batch effect**: technical differences between samples processed at different times, places or ways.
- **Peak**: a genomic region with many more reads than background (a binding site or open region).
- **Nucleosome**: ~147 bp of DNA wrapped around a histone core, the basic unit of chromatin.
- **Histone mark**: a chemical modification on a histone tail that signals chromatin state (e.g. H3K27ac).
- **CRISPR-Cas9 / sgRNA**: a programmable DNA-cutting system / the short guide RNA that points it at a target.
- **Lentivirus / MOI**: a virus used to insert genes into cells / multiplicity of infection, the viruses per cell.
- **Mass spectrometry (MS)**: measures the mass-to-charge ratio (m/z) of ionized molecules.
- **Peptide**: a short piece of protein.

## Sequencing basics

Most data come from **short-read sequencing** (Illumina). DNA (or RNA copied into DNA) is broken into fragments, short known **adapter** sequences are attached (making a **library**), the fragments are copied by **PCR**, and the machine reads 50–300 bases from each fragment. Each output string is a **read**. With **paired-end** sequencing, both ends of each fragment are read, giving files R1 and R2. Long-read technologies (PacBio, Oxford Nanopore) read thousands of bases per molecule but are noisier and cost more per base.

## Sequence files

**FASTA**: a header line starting with `>`, then the sequence. It is used for genomes, transcripts and proteins. A UniProt header looks like `>sp|P04637|P53_HUMAN Cellular tumor antigen p53 OS=Homo sapiens OX=9606 GN=TP53`, where sp = Swiss-Prot (tr = TrEMBL), OX = NCBI taxonomy ID (9606 human, 10090 mouse), and GN = gene name.

**FASTQ**: raw reads with quality scores, 4 lines per read:
```
@read_id
ACGTTGCA...
+
IIIIHHG#...
```
Line 4 gives one quality character per base. A **Phred score** is Q = −10·log10(P_error): Q10 = 1 in 10 chance the base is wrong, Q20 = 1%, **Q30 = 0.1%** (the usual quality bar), Q40 = 0.01%. Characters encode Q + 33 as ASCII ("Phred+33"): `!` = Q0, `+` = Q10, `5` = Q20, `?` = Q30, `I` = Q40.

## Alignments: SAM/BAM/CRAM

**Alignment** (mapping) finds where each read came from in the **reference genome**, the standard sequence everyone compares against. DNA aligners: BWA-MEM, Bowtie2. RNA aligners must handle reads that span spliced-out introns (see Unit 1): STAR, HISAT2. The output is **SAM** (text), **BAM** (compressed binary; sort by position and index with a `.bai` file for fast lookup), or **CRAM** (smaller, because it stores only differences from the reference, so you need that exact reference to read it). **Coverage** or **depth** is how many reads overlap a position ("30× genome").

Each SAM line has 11 required fields: QNAME (read name), **FLAG**, RNAME (chromosome), **POS** (1-based leftmost position), **MAPQ**, **CIGAR**, RNEXT/PNEXT/TLEN (mate information), SEQ, QUAL. Optional tags follow (NM:i:, and CB:Z: for the cell barcode in single-cell data).

- **FLAG** is a bitfield of yes/no properties summed together: 1 paired, 2 properly paired, **4 unmapped**, **16 reverse strand**, 256 secondary alignment, **1024 duplicate** (a PCR or optical copy of another read), 2048 supplementary (a read split across two locations).
- **CIGAR** spells out the alignment: `M` aligned (match or mismatch), `I` insertion, `D` deletion, **`N` skipped reference (an intron, for RNA)**, `S` soft clip (unaligned bases kept in the record), `H` hard clip (removed). `50M1000N50M` = a read split across a 1-kb intron.
- **MAPQ**: Phred-scaled confidence that the read is placed correctly. 0 usually means it fits equally well in several places (a **multi-mapper**).

## Variants: VCF

**VCF** lists variants. Columns: CHROM, POS (1-based), ID (rsID), REF (reference allele), ALT (alternative allele), QUAL, FILTER (PASS if it passed filters), INFO (key=value annotations such as AF = allele frequency, DP = depth), FORMAT, then one column per sample. A **genotype** (GT) says which alleles that person has: `0/0` both reference (homozygous ref), `0/1` one of each (heterozygous), `1/1` both alternative. A `|` instead of `/` (`0|1`) means **phased**: we know which chromosome copy carries which allele. Indels include the preceding base: `chr1 100 . A AT` = insertion of T after position 100.

## Intervals and annotations: BED and GTF/GFF

Coordinates come in two conventions. **1-based, inclusive** counts the first base as 1 and includes both ends. **0-based, half-open** counts the first base as 0 and excludes the end (like Python slicing).

**BED**: `chrom start end [name score strand …]`, **0-based, half-open**. `chr1 0 100` = the first 100 bases (1-based 1–100). Used for **peaks**, target regions and blacklists (regions known to give artifacts). narrowPeak is an extended BED from the peak caller MACS.

**GTF/GFF3**: gene annotation (see Unit 3) with **9 columns**: seqname, source, feature (gene/transcript/exon/CDS/UTR…), **start, end (1-based, inclusive)**, score, strand, frame, attributes. GTF attributes: `gene_id "ENSG…"; transcript_id "ENST…";`. GFF3 attributes: `ID=…;Parent=…`. GENCODE and Ensembl distribute GTFs that quantification tools read.

Mixing BED (0-based) with VCF/GTF/SAM (1-based) is a classic off-by-one bug.

## Reference genome builds

A reference genome is periodically rebuilt as an improved **assembly** (build).
- **GRCh37 ≈ hg19** (2009) and **GRCh38 ≈ hg38** (2013). GRC = Genome Reference Consortium names; hg = UCSC names. The main chromosome sequences match between each pair, but UCSC writes `chr1`/`chrM` while GRC/Ensembl writes `1`/`MT`, and the hg19 mitochondrial sequence differs from GRCh37's.
- **Coordinates differ between builds.** BRAF V600E is chr7:140,453,136 in hg19 and chr7:140,753,336 in hg38. Convert with liftOver or CrossMap (see Unit 3). Never mix builds.
- **T2T-CHM13** (2022) is the first complete, gap-free human assembly. GRCh38 is still the default. Mouse: mm10 (GRCm38), mm39 (GRCm39).
- The gene annotation release (GENCODE vXX / Ensembl release) is separate from the build. Report both.

## Bulk RNA-seq

RNA-seq measures **gene expression** (how much RNA each gene makes) in a sample. RNA is extracted, mRNA is enriched by its poly(A) tail (or abundant ribosomal RNA is removed), then copied into **cDNA** by reverse transcriptase and sequenced. Reads are either aligned (STAR) and counted per gene (featureCounts, HTSeq), or **pseudoaligned** to transcripts (salmon, kallisto), which is faster and skips exact base-by-base alignment. Units:
- **Raw counts**: integers per gene. Required by **DESeq2/edgeR**, which model counts with a negative binomial distribution.
- **CPM**: counts per million reads (corrects for sequencing depth only).
- **RPKM/FPKM**: correct for depth, then gene length (per kilobase). Totals differ between samples, so values compare poorly across samples.
- **TPM**: correct for length first, then scale so each sample sums to 1,000,000. Better for comparisons within and across samples. Neither replaces proper statistical normalization.
- **Differential expression** reports **log2 fold change** (log2 of the ratio between conditions; +1 = doubled) and p-values adjusted for testing thousands of genes, controlling the **false discovery rate (FDR)** with the Benjamini–Hochberg method. Results are shown as volcano plots.

## Single-cell RNA-seq

Bulk RNA-seq averages over millions of cells. Single-cell RNA-seq measures each cell separately. In droplet methods (10x Genomics Chromium), each cell is captured in an oil droplet with a bead carrying a **cell barcode** (which cell) and a **UMI**, a unique molecular identifier (which original RNA molecule). Counting distinct UMIs per gene ignores PCR copies. Cell Ranger (or STARsolo, alevin-fry) outputs a **sparse** (mostly zeros) cell-by-gene count matrix. 10x's MTX files are genes × cells, while **AnnData (.h5ad)**, the Python (scanpy) standard, is **cells × genes**:
- `adata.X`: the matrix, rows = cells (obs), columns = genes (var)
- `adata.obs`: per-cell metadata (cell type, donor, batch, QC metrics)
- `adata.var`: per-gene metadata (Ensembl ID, symbol)
- `adata.obsm`: low-dimensional embeddings (X_pca, X_umap); `adata.layers`: alternative matrices (raw counts); `adata.uns`: everything else

Standard pipeline: quality control (drop cells with few genes, cells with a high **mitochondrial read fraction**, a sign of broken cells, and **doublets**, droplets holding two cells), `normalize_total` + `log1p`, select highly variable genes, PCA, nearest-neighbor graph, **Leiden** clustering, **UMAP** for 2D plots, then name clusters by **marker genes** (genes specific to a cell type). **Batch effects**, technical differences between runs, are corrected with Harmony or scVI. R users use Seurat.

## Chromatin assays

DNA in the nucleus is wrapped around histone proteins in units called **nucleosomes** (~147 bp each). Tightly packed chromatin is mostly inactive and open chromatin is active.
- **ChIP-seq** (chromatin immunoprecipitation): proteins are crosslinked to DNA, the DNA is fragmented, an antibody pulls down one TF or histone mark, and the attached DNA is sequenced. **Peaks**, regions with far more reads than a control, are called with MACS2/3. **Histone marks** to know: **H3K4me3** = active promoters, **H3K27ac** = active enhancers and promoters, **H3K4me1** = enhancers, **H3K27me3** = Polycomb-silenced genes, **H3K36me3** = bodies of transcribed genes, **H3K9me3** = tightly packed heterochromatin. (H3K27ac = histone H3, lysine 27, acetylated.) CUT&RUN and CUT&Tag are lower-input alternatives.
- **ATAC-seq**: the enzyme **Tn5 transposase** inserts sequencing adapters wherever DNA is accessible, mapping **open chromatin**. scATAC-seq does this per cell. DNase-seq is the older method.
- **Hi-C**: measures which parts of the genome touch in 3D (TADs and loops; see Unit 1).

## CRISPR screens

**CRISPR-Cas9** is a DNA-cutting enzyme guided by a short RNA (**sgRNA**, ~20 bases matching the target). Cuts in a gene usually create frameshift indels that knock it out. In a **pooled screen**, a library with ~4–10 guides per gene (e.g. Brunello) is delivered by **lentivirus** (a virus that inserts DNA into the cell's genome) at low **MOI** (multiplicity of infection, ~1 guide per cell). Cells are then put under selection (growth, drug, sorting), and guides are counted by sequencing before and after. **Depleted** guides mark genes the cells need (essential genes "drop out"); enriched guides mark genes whose loss helps (e.g. drug resistance). Analysis tools: MAGeCK, BAGEL, Chronos (DepMap; see Unit 3). Variants: knockout (Cas9), **CRISPRi** (inactive dCas9 fused to the KRAB repressor turns genes down), **CRISPRa** (activation), base and prime editing. **Perturb-seq** reads out each perturbation with single-cell RNA-seq, a major data type for perturbation-prediction models.

## Mass-spectrometry proteomics

**Mass spectrometry** measures the mass-to-charge ratio (**m/z**) of ionized molecules. In **bottom-up** proteomics, proteins are cut into **peptides** by the enzyme **trypsin** (which cuts after K or R, but not before P). Peptides are separated by liquid chromatography and measured by tandem MS (**LC-MS/MS**): one scan measures intact peptides, then selected ones are fragmented and their fragments measured. Fragment spectra are matched to peptides predicted from a protein database, with false hits controlled by a **target-decoy** search against reversed or shuffled sequences. Acquisition modes: **DDA** (data-dependent: fragment the most intense peptides) and **DIA** (data-independent: fragment everything in m/z windows; more reproducible). Quantification is label-free (LFQ) or uses isobaric **TMT** tags to multiplex samples. Tools: MaxQuant, DIA-NN, FragPipe. Data repository: PRIDE.

## How you'll see this in a paper

- "Aligned to GRCh38 with STAR (GENCODE v38), quantified with salmon": build, annotation and tool.
- "Cells with <200 genes or >20% mitochondrial reads were removed": single-cell QC.
- "Peaks called with MACS2 (q < 0.01); ENCODE blacklist regions excluded."
- "One-hot encoded 131 kb sequences predicting ENCODE coverage tracks": a genomics model's input and labels.
